Follower Lens does not log into Instagram, collect your Instagram password, or claim to identify blockers. A missing account can have many causes, including deactivation or a username change.

Export Instagram data

In Instagram / Accounts Center, request a download of your information and choose JSON if available. Include Followers and following. Instagram's menu wording can change over time.

  1. Request your Instagram information in JSON format.
  2. Download the ZIP when Instagram makes it available.
  3. Import the ZIP directly here. If ZIP parsing isn't supported by your browser, extract it on your phone and select the follower/following JSON files instead.
  4. Import again later. The app compares the new snapshot with the previous one.

Everything is stored in this browser using IndexedDB. Clearing browser/site data can remove your history, so use Backup local history periodically.
